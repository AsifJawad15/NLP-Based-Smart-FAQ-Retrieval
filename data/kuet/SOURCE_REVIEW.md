## Club and collection notes

Club coverage: CSEA, SGIPC, HACK, KCC, KDS, KBEC, IRCC, KUET Theatre, CADers, plus a general student-activities overview. KDS/IRCC/Theatre/CADers descriptions use historical official Fab Lab records indexed by web search. Direct archive downloads failed because the www2 host certificate expired; certificate validation was not disabled. They support historical activities only, not current committees, recruitment or calendars. KBEC is a club-owned first-party source rather than a university page. Its search-indexed description supplies the overview; the direct HTML response contains only the application title. The BHTPA directory was readable through web browsing, while direct snapshot download returned 403. Its inconsistent area units were excluded. No full snapshot is claimed for these failed or JavaScript-only fetches.

The expanded validation set has 100 developer-authored queries (70 answerable, 30 unanswerable). The smoke set has 60 (45/15), including unsupported leadership, unknown clubs, prices and schedules. These sets are not human evaluation. Human feedback is collected separately in the app and exported by the evaluator.
